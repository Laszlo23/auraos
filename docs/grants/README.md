# Aura OS — grant outreach checklist

Mailing every chain from the OS **cannot auto-submit** third-party portals (Google Forms, Questbook, Foundation apps). That would break ToS and usually requires human KYC.

What we shipped instead:

1. **Live application kit** — https://aibusiness.fun/grants  
   - Copy one-liner / 250 / long form / architecture / traction  
   - Download full markdown kit  
   - Per-programme **Open apply** + **Copy pitch**
2. **SMTP connected** as `founders@aibusiness.fun` — agents may draft; you approve sends in Akquise.
3. **Grant Hunter** — `/akquise?template=grant_hunter` pre-fills the research brief.
