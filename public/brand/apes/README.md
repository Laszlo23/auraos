# Aura OS Landing Page Mascot Assets

This directory contains the BAYC-style mascot images displayed in the landing page hero "crew" strip.

## Required Images

Place these 6 PNG images in this directory:

1. **boss-magma.png** - Magma/lava pattern ape in black suit with gold jewelry (burgundy background)
2. **beanie-gold.png** - Blue ape with black beanie and hoodie (gold background)
3. **nvg-lava.png** - Lava pattern ape with neon-green night vision goggles and leather jacket (cyan background)
4. **xeyes-lime.png** - Neon-lime fur ape with X eyes and stitched mouth (orange background)
5. **straitjacket-lime.png** - Blue ape with gold glasses in straitjacket (lime background)
6. **varsity-teal.png** - Brown ape in lime varsity jacket with trucker cap (teal background)

## Image Specs

- **Format**: PNG with transparency or solid background
- **Recommended size**: 512×512px or larger (displayed at 128-144px)
- **Style**: BAYC-inspired street/premium crypto aesthetic

## Attribution

These are user-provided design reference mascots for visual vibe, not claiming BAYC ownership or affiliation. Treat as placeholder design assets.

## Usage

The landing page (`src/routes/index.tsx`) displays these images in a horizontal scrollable strip below the hero CTAs with:
- Thick neon lime borders (2px)
- Glow shadows on hover
- Responsive layout (mobile scroll, desktop grid)
- Alt text describing each mascot without ownership claims
